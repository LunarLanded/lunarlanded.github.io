# FAQ

??? question "The plugin doesn't show up in the Plug-in Manager"

    Lightroom only scans the `Modules` folder at startup. Fully quit Lightroom
    (not just close the window) and reopen it. If it still doesn't appear, add
    it manually via **File → Plug-in Manager → Add**.

??? question "My licence key is rejected"

    Check for a trailing space when pasting. Keys are 24 characters, grouped in
    fours. If it still fails, you may have hit the three-machine limit —
    deactivate an old install from the same dialog.

??? question "Does it work with Lightroom CC / mobile?"

    No. Adobe's cloud Lightroom has no plugin API. Lightroom **Classic** only.

??? question "Can I use it on both my Mac and my PC?"

    Yes. The three-seat limit counts machines, not platforms.

??? question "Processing is very slow"

    Smart Previews speed things up considerably. Select your photos and use
    **Library → Previews → Build Smart Previews** before running a large batch.
