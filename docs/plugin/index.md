## Requirements

| Requirement | Minimum |
| ----------- | ------- |
| Lightroom Classic | 12.0 |
| macOS | 12 Monterey |
| Windows | 10 (64-bit) |

!!! danger "Lightroom CC is not supported"

    Adobe's cloud-based Lightroom (the one without "Classic" in the name) has
    no plugin architecture. This plugin requires **Lightroom Classic**.
